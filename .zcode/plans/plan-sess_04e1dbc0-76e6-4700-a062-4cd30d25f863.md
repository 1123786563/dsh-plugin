# 拉取 dsh-web 到本地并 Fork 自维护

## 背景发现

- `/Users/wuyongjun/trea/dsh-plugin/dsh-web/` 已存在，但**只是一次被中断的浅克隆残留**：目录内仅有 `.git`（含 `shallow.lock` 锁文件、HEAD 指向 `refs/heads/.invalid`），无任何工作区文件，需删除重来。
- 原仓库 `zhu1090093659/dsh-web`：原创公开仓库（非 fork），默认分支 `dev`，2132 个提交，pnpm monorepo（TypeScript + Playwright）。
- `gh` CLI 已登录账号 `1123786563`，具备 fork 所需的 repo 权限。
- 父目录 dsh-plugin 本身是 git 仓库，需防止嵌套仓库被误提交。

## 实施步骤

1. **清理残留**：删除中断的克隆残留 `rm -rf /Users/wuyongjun/trea/dsh-plugin/dsh-web`（已确认其中只有损坏的 .git、无任何代码文件）。
2. **Fork 仓库**：`gh repo fork zhu1090093659/dsh-web --clone=false`，在你的账号 `1123786563` 名下建立 fork。
3. **克隆自己的 fork**：`git clone https://github.com/1123786563/dsh-web.git /Users/wuyongjun/trea/dsh-plugin/dsh-web`，默认检出 `dev` 分支，保留完整历史（便于自维护与推送）。
4. **配置上游同步**：
   - `git remote add upstream https://github.com/zhu1090093659/dsh-web.git`
   - `git remote set-url --push upstream DISABLE`（防止误推到上游原仓库）
5. **隔离父仓库**：在 dsh-plugin 的 `.gitignore` 中追加 `dsh-web/`，防止嵌套仓库被误当作 gitlink 提交。该修改**只在本地生效、不提交**（dsh-plugin 仓有 Mimosa 门禁拦截提交的存量问题，提交由你以后自行处理）。
6. **安装依赖**：在 dsh-web 目录执行 `pnpm install`（不额外执行 `playwright install` 下载浏览器，需要跑 e2e 时再装）。
7. **验证**：确认 `git log` 正常显示 dev 分支提交、`git remote -v` 显示 origin（你的 fork）与 upstream（原仓库）、依赖安装成功。

## 日常维护方式（交付后说明）

- 修改后 `git push origin dev` 推到你自己的 fork；
- 同步上游更新：`git fetch upstream && git merge upstream/dev`。
