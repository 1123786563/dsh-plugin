# 会话的计费归属以 agent 预设为键（预设→客户映射）

运营者代跑形态下，计费归属不新增任何会话创建交互：插件维护「agent 预设 ID → 客户」映射表（在收银台面板编辑），会话启动时读 `session.header.agentPreset` 查表定归属，映射缺失则记入内部户（运营者自己的主体，照常计量、永不阻断）。理由：一个客户对应一组项目预设贴合代跑心智，实现最薄。v1 不做改绑：已上报事件不可变，中途改绑会造成归属矛盾。

## Considered Options

- 每次开新会话弹选择器指定客户——被否：侵入会话创建流程，运营负担最重。
- 事后改绑——被否（v1）：事件已按原归属上报且不可变。

## Consequences

- 客户上线流程 = 建客户 + 建预设 + 收银台里连一条映射。
- 内部户顺带提供「运营者自身成本」视图。
